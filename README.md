# Yucca_Clone
A modern and responsive frontend clone inspired by the Yucca Packaging website, built using HTML and CSS with interactive hover effects, smooth animations, marquees, and premium UI transitions.

## 🚀 Live Preview
Click here to here to view the live demo ---> https://riyajayaswal.github.io/Yucca_Clone/
Original website --> https://yucca.co.za/

## ✨ Features

- Responsive modern UI
- Animated hero sections
- Dynamic background image changes on hover
- Infinite marquee animation
- Product image zoom effects
- Sliding hover overlays
- Interactive buttons and cards
- Smooth CSS transitions and transforms
- Footer hover animation
- Clean and aesthetic layout  


## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- CSS Animations
- CSS Transforms
- Hover Effects
